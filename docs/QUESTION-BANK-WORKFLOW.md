# 문제은행 업무 흐름과 화면 설계

환경교육 자격 과정의 문제은행 고도화에서 검토, 문제은행 조회, 통계, 시스템 관리 기능을 담당했습니다. 개발 전에 출제부터 시험지 감수까지 전체 흐름을 보드로 정리하고 메뉴별 담당 범위를 나눴습니다.

## 전체 업무 흐름

```text
출제계획 → 출제위원 배정 → 문항 출제
                           ↓
검토계획 → 검토위원 배정 → 적합/부적합/보류/폐기
                           ↓
선정계획 → 선정위원 배정 → 본문항·예비문항 선정
                           ↓
출제위원장 검토 → A/B형 시험지 편집 → 운영위원장 감수
```

문항을 단순히 작성·승인하는 흐름으로 보지 않고, 계획과 위원 배정, 단계별 완료, 수정 요청, 완료 취소를 각각 상태로 나눴습니다. 선정은 필요한 문항의 1.5배를 후보로 구성하고 본문항과 예비문항을 구분하는 운영 규칙도 화면 흐름에 반영했습니다.

## 담당 기능

### 검토 관리

- 검토계획과 과목별 대상 문항 구성
- 검토위원 배정과 진행률 확인
- 적합, 부적합, 보류(수정 필요), 폐기 판정
- 완료 이후 수정이 필요한 경우 완료 취소와 재검토

### 문제은행 관리

- 분류·유형·난이도·판정 상태별 문항 조회
- 문항 상세, 정답, 해설, 참고문헌, 변경 정보 확인
- 문항 보유 현황과 분류 일괄 이동
- 출제·검토·선정 단계에서 동일 문항 정보를 재사용

### 통계와 시스템 관리

- 과목·분류·난이도별 문항 현황 집계
- 사용자와 위원 권한 관리
- 과목·분류 코드 관리
- 접근 가능한 메뉴와 작업 범위를 역할별로 제한

## 설계하면서 정한 기준

- 계획에 포함되지 않은 문항은 검토할 수 없음
- 담당 위원에게 배정된 문항만 판정 가능
- 보류 문항은 수정 후 다시 검토해야 완료 가능
- 완료된 계획은 일반 수정 대신 완료 취소 이력을 남김
- 시험지 감수 단계에서는 문항 내용을 직접 편집하지 않음
- 진행률은 화면 입력값이 아니라 배정 수와 완료 수로 계산
