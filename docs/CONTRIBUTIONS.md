# 담당 업무와 기여 내용

SVN 작업 사본에서 작성자 `joshuajeon`으로 확인되는 Controller, Service, Mapper와 화면 파일을 기준으로 정리했습니다.

## 신청자 기능

- 모집 중인 사업과 신청 가능한 일정 조회
- 신청자 기본정보와 기존 신청 여부 확인
- 기관별 정원, 시험실 수용 인원, 현재 신청 인원 검증
- 신청정보 생성과 수험번호 부여
- 신청 설문과 문항별 답변 저장
- 일반 신청과 체험 신청 분리
- 신청 취소, 사진 변경, 수험번호 재생성
- 신청 결과와 성적증명서 조회·출력
- 신청 완료·취소 안내 메일

## 사업계획과 기관 운영

- 사업계획 목록·상세·등록·수정·삭제
- 기관별 신청 현황과 전체 현황 조회
- 기관 담당자 변경 신청
- 운영 시험실과 수용 인원 확인
- 모집 데이터와 운영자료 조회
- 시험지 유형별 규칙과 처리 상태 관리

## 예산 변경

- 기관 예산과 운영비 세부항목 조회
- 변경 요청 저장과 상태 변경
- 변경 전·후 세부 금액 비교
- 변경 요청 이력 조회
- 기관용·관리자용 화면과 API 구성

## 보조금과 정산

- 보조금 반환 요청 목록과 상태 처리
- 계좌 확인 결과 관리
- 배송 주소와 배송 수량 확인
- 정산자료 전송 목록과 엑셀 다운로드
- 반려 상태와 반려 사유 저장
- 반려 안내 메일 발송
- 승인 시 정산 관련 값 갱신
- 답안 수합과 운영자료 상태 처리

## 워크숍과 안내 메일

- 워크숍 대상 기관과 신청 목록 조회
- 사용자별 이름, 이메일, 기관정보 검증
- 메일 제목·템플릿·발신자 구성
- 발송 성공 대상의 발송일시 갱신
- 실패 대상과 실패 원인 반환
- 체험 신청자 대상 개별 메일 발송

## 보고서와 게시판

- 성적·신청 결과 리포트 데이터 조회
- 사진과 첨부자료 경로 구성
- 보고서 출력 이력 저장
- 공지사항 등록·수정·삭제와 답변
- 쪽지 읽음 처리와 사용자 검색

## SVN 작업 사본에서 확인한 범위

| 프로젝트 | 본인이 마지막으로 수정한 파일 | 주요 영역 |
|---|---:|---|
| 교육사업 운영 시스템 | 205개 | 신청, 사업계획, 예산, 정산, 워크숍, 보고서 |

파일 수는 커밋 수나 기여 비율이 아니라 현재 SVN 작업 사본에서 확인 가능한 변경 범위입니다.
